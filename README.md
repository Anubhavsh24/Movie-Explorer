# 🎬 Movie Explorer

A movie search web application built using **HTML, CSS, and JavaScript**, powered by the OMDb API.

## 🌐 Live Demo

[**Explore Movies →**](https://Anubhavsh24.github.io/movie-explorer/)

## 📌 About the Project

Movie Explorer is a web application that allows users to search for movies and explore information about their favourite films.

It uses the OMDb API to retrieve movie information dynamically and display the results through a simple and user-friendly interface.

The project demonstrates how frontend technologies can interact with external APIs to create dynamic web applications.

## ✨ Features

- 🔍 Search movies by title.
- 🎥 Fetch movie information using the OMDb API.
- 🖼️ Display movie posters.
- ⚡ Dynamic search results.
- 🌐 API integration using JavaScript Fetch API.
- 📱 Simple and user-friendly interface.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Web page structure |
| CSS3 | Styling and layout |
| JavaScript | Application functionality |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Anubhavsh24/movie-explorer.git
```

### 2. Navigate to the project directory

```bash
cd movie-explorer
```

### 3. Open in VS Code

```bash
code .
```

### 4. Configure the OMDb API

This project uses the OMDb API.

Obtain an API key from [OMDb API](https://www.omdbapi.com/apikey.aspx) if you need your own key, and configure it in `project.js`.

### 5. Run the application

Open `index.html` using VS Code Live Server.
